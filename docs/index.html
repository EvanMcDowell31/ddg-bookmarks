Your DuckDuckGo bookmarks, from Claude Code.

Read, add and remove bookmarks in DuckDuckGo for Mac while it runs. Every change is backed up first, and nothing restarts your browser.

/plugin marketplace add EvanMcDowell31/ddg-bookmarks

Three ways to add to your bookmarks

One small script does the writing. The plugin wraps it in a command, a workflow and a skill, so you can ask in your own words.

Command

/ddg-bookmarks:add

"Bookmark these into Work > Docs." It checks each link loads, skips any you already have, and files the rest where you said.

Workflow

/ddg-bookmarks:bookmark-projects

Agents find your GitHub repositories from the last year, the sites they publish and, if you ask, the web apps running on your Mac. Then one checks each link and merges the new ones into a Projects folder. It only adds; it never moves or removes.

Tool

ddg-bookmarks

tree, find, add, remove. JSON in and out, --merge to add only what's missing, and --dry-run to see a change before it's made.

Install

You need macOS, DuckDuckGo for Mac (the direct download or the App Store build) and Python 3, which macOS's command line tools include.

Claude Code

In a session, one after the other:

/plugin marketplace add EvanMcDowell31/ddg-bookmarks
/plugin install ddg-bookmarks@ddg-bookmarks

On macOS 14 and later, the first read asks you to let your terminal access data from other apps. A terminal with Full Disk Access isn't asked.

Irie

Clone the repository and copy irie/ddg-bookmarks.toml to ~/.config/irie/plugins/, with its path set to your clone's skills/bookmarks. Turn it on in Settings › Plugins. Then type this in a task bar:

:bookmark https://example.com into Reading

By hand

The script runs on its own, with no packages to install:

python3 -I skills/bookmarks/scripts/ddg_bookmarks.py tree
python3 -I skills/bookmarks/scripts/ddg_bookmarks.py \
  add --title Docs --url https://example.com/docs \
  --into Work --merge

How it stays safe

DuckDuckGo keeps bookmarks in a Core Data SQLite store and reads it afresh each time. The script writes rows the way the app's own code does, so they're ready the next time it looks.

  • A backup firstEvery write saves a one-file copy beside the store before it changes anything.
  • All or nothingEach change is one transaction that ends with an integrity check, so a failure leaves your bookmarks as they were.
  • Written as the app writesNew rows get a UUID, a version and a modified time, and their folder is marked changed, as the app's BookmarkEntity does. A removal marks rows for deletion, as the app's own does.
  • Strict about what it opensOnly an existing DuckDuckGo store, in WAL mode, with the tables it knows. A mistyped path never creates a database.
  • Safe to repeatWith --merge, a folder already there takes only what it lacks, and a link already there is skipped.
  • Only web linksjavascript:, data: and other links that run code are refused.

Questions

When do new bookmarks show up?

DuckDuckGo reads its bookmarks again the next time you bookmark, edit or move something in it, or when it next starts. Until then they're saved but not yet shown. Nothing here restarts your browser.

Is this made by DuckDuckGo?

No. It's an independent open-source project, not made or endorsed by DuckDuckGo. It learned the shape of the store by reading DuckDuckGo's open-source browser code, which is public under the Apache License.

Does it work with DuckDuckGo Sync?

Adds and removals are written as the app writes its own, so they should sync like any other, but that hasn't been tested. The script prints a note when your store shows Sync has run.

How do I undo a change?

Remove what you added with ddg-bookmarks remove "Folder > Title". Every write also keeps a backup beside the store, but don't copy one back while DuckDuckGo runs.

Windows, iPhone, other browsers?

Not today. It works with DuckDuckGo for Mac's own store only.
